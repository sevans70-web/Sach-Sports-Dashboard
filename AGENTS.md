# Sach Sports dashboard scope

Unless Sach explicitly limits a request to one sport, shared dashboard changes
apply across NBA, NFL, NHL, CBB (college basketball), and CFB (college football).
Soccer, MLB, and WNBA are deferred at Sach’s explicit request on October 30, 2026.
Check the shared implementation and every sport's integration; do not report a fix as universal
based only on an NBA check.

Play of the Day, Best Value, and Long Shot are shared features. Distinguish a
working feature with no qualifying source data from a missing integration.
Preserve original selections after kickoff/tipoff and identify saved pregame
prices. Label next-slate selections clearly when there are no games today.

WNBA and MLB are intentionally hidden. Deferred Soccer/MLB/WNBA work remains on
the tracker’s deferred tab; do not expand active acceptance requirements to them.
Preserve retired sports’ capture, historical records, and shared feature support without unhiding them unless requested.
Never fabricate a pick, GI score, odds, result, or model probability to fill a card.

Featured categories must use different players on every dashboard. Choose the next qualifying player; never repeat one player across categories or invent a replacement.
