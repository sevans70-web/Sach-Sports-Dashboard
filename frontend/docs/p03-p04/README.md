# P03/P04: exact EV evidence and forecast/selection display

Problem: full player cards trusted URL pick/projection flags and could show a fabricated OVER/UNDER as a sportsbook-backed selection even when EV evidence was unavailable. Football ranking forecasts also occupied a slot labelled Sach Pick. Shared saved-pick checks did not reject an explicitly failed forecast, a retimed probability calculation, or a calculation bound to another quote.

Full cards now obtain projection,selection,line,book,odds and probabilities from matched server-side saved evidence. URL selection/projection flags cannot establish a model forecast or supported selection. Unverified URL lines are labelled Reference Line. The exact server line overrides URL context. Loading,failure and identity changes withhold evidence; previous player state cannot flash onto the next player. A saved selection shows the actual book and side-specific odds. A projection without a selected price stays Forecast Direction/Forecast only. Primary EV and expanded probability remain hidden until the same saved-selection evidence has been matched. This uses the shared full card for all8 sports.

Shared saved-pick checks now reject explicitly unavailable/failed forecasts, forecast/selection clock mismatches, decisions before quote update and mismatched price-comparison bindings. New runtime probabilities bind sport,market,player,game,book,quote,line,both prices and calculation time. Existing original archives without the new optional binding remain readable; no historical backfill or price/probability edits. EV retains selected-side American-odds payout and push-aware win/loss arithmetic. Model validation/accuracy remains P01; no new model approved.

Validation before release:433 tests and production build pass. Includes OVER/UNDER,positive/negative odds,pushes,missing/stale quotes,all8 sport evidence checks,each modified binding field,URL-spoof rejection,exact-line override and unchanged saved probabilities after kickoff. Browser reproduced the old bug with a fabricated URL: OVER1.5 and projection30 appeared as Sportsbook-backed selection despite no evidence. Post-release browser/production verification recorded in tracker.

Read-only pre-release audit enumerated75 market routes across all8 sports:43populated,721rows,59availableEV calculations with no arithmetic or identity mismatches.6CFB routes returned500 (confirmed provider timeout);10hiddenWNBA routes andsoccer timed out. Empty feeds and unsupported markets did not produce fabricated EV. These source failures prevent claiming a clean all-market availability pass; they are separate from EV arithmetic and display rules. MLB/WNBA stayed hidden; no source writes invoked by the audit script. Actual normal ranking GETs may perform the app's existing routine capture.

No P01 candidate/research coefficients are in this release. Historical records,frozen cohorts,grades,prices and visibility settings are preserved.
