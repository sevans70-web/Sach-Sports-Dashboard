# NFL N01, N02 and N03 grouped coverage work

N01 adds the missing passing_interceptions market to the NFL contract, QB tab, OWL/SGO aliases, player history, observed passing-category statistics, units, recent-role cohort and QB performance grouping. Passing interceptions cannot use a defensive INT table and require a resolved QB position. No interception probability model is fabricated: the existing heuristic explicitly abstains and unsupported fitted-model output remains unavailable. Genuine pregame sportsbook quotes are required before publishing a backed line;the interceptions market does not generate unpriced backup-QB watch cards when its quote feed is empty.

N02 hardens shared football combined-history parsing: every requested component must exist for the event; blank or missing rushing/receiving components cannot become a partial combined total. Real zero components are retained. Existing public game-by-game combined parsing and observed-stat parsing already require complete components; the shared history-values helper now follows the same rule. The unused legacy summary helper is also made strict. No frozen history is rewritten.

N01/N02/N03 full-game progress now parses official observed box-score rows once per fixture. Only q1 markets invoke reconciled play-by-play extraction. This removes repeated per-player parsing of full quarter tape for full-game offensive and defensive cards, while preserving period-specific rules. Official IDs, unknown stats and fractional sacks remain intact. Defense performance requests now select sacks/solo/combined tackles instead of falling into the offensive group.
